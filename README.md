## 📋 Visão Geral

**Stock Control** é uma aplicação robusta desenvolvida para pequenos e médios negócios que necessitam de um controle rigoroso de inventário e registro de vendas. O sistema orquestra desde o cadastro simples de produtos até análises financeiras complexas com exportação para formatos profissionais (PDF e TXT).

Esta é a **Versão 2.0 (Final)**, marcando o encerramento do desenvolvimento com todas as funcionalidades de vendas e relatórios financeiros concluídas.

---

## ✨ Funcionalidades

### 📦 Gestão de Estoque (v1.0 Core)
- **CRUD Completo**: Adicionar, remover, atualizar e visualizar produtos.
- **Categorização**: 11 categorias pré-definidas (Eletrônicos, Roupas, Alimentos, etc).
- **Relatório de Inventário**: Exportação detalhada em TXT e PDF.
- **Persistência**: Salvamento automático em JSON.

### 💰 Sistema de Vendas (v2.0 New)
- **Registro de Vendas**: Cadastro de transações com múltiplos itens.
- **Validação Automática**: Verificação de estoque disponível antes da venda.
- **Histórico**: Consulta paginada de todas as vendas realizadas.
- **Relatório Financeiro**: Análise de receita, ticket médio e performance.
- **Insights**: Top 5 produtos mais vendidos e receita por categoria.
- **Alertas**: Notificação de produtos com estoque baixo (< 3 unidades).

## 🚀 Como Executar

### Pré-requisitos
- .NET 10 SDK ou superior.
- Terminal com suporte a cores (Console Windows, Windows Terminal, iTerm2, etc).

### Instalação Rápida
```bash
git clone https://github.com/alissonavm911/StockControl.git
cd StockControl
dotnet run
```

## 📖 Guia de Uso (Menu)

| Opção | Funcionalidade | Descrição |
|-------|---|---|
| **1-5** | **Gestão de Produtos** | Controle total do seu catálogo de itens. |
| **6** | **Relatório de Estoque** | Gere PDFs profissionais do seu inventário atual. |
| **7-9** | **Gestão de Vendas** | Registre transações e consulte seu histórico. |
| **10** | **Relatório Financeiro** | Veja quanto você vendeu e quais produtos dão mais lucro. |
| **0** | **Sair** | Salva todos os dados com segurança e encerra. |
